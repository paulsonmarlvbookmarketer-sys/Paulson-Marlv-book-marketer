# Paulson Marlv Book Marketing - Website
Open this folder in VS Code and run "Live Server" on index.html.
- css/style.css  : all styling (colors are variables at the top)
- js/main.js     : animations, menu, forms
- images/        : add brandlogo.png, profilepicture.png, techpic.png
- Forms post to Formspree (https://formspree.io/f/xljjvezg) and then redirect to thank-you.html
- Emails: auto-confirmation to the visitor needs Formspree's Autoresponder (paid plan); enable it in your Formspree dashboard.
- Pricing: search packages.html for [PRICE] and [DURATION].
- Social links: edit the href="#" in the footer of each page.
- Legal pages are templates: have them reviewed before publishing.
- CMS suggestion: Decap CMS (free, Git-based) or Pages CMS; both work with GitHub. GitHub Pages has no backend, so Formspree handles forms.
